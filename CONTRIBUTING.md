# Guía de contribución

Para completar la práctica:

1. Haz fork de este repositorio.
2. Clona tu fork.
3. Crea una rama llamada `ejercicio`.
4. Crea un archivo en `estudiantes/`.
5. Haz commit de tus cambios.
6. Sube tu rama a GitHub.
7. Abre una Pull Request hacia este repositorio original.

No trabajes directamente sobre la rama `main`.
