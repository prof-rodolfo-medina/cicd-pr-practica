# cicd-pr-practica
Repositorio base para practicar fork, ramas, commits y pull requests en GitHub.

# Práctica de Pull Request - CI/CD

Este repositorio se usará para practicar el flujo de trabajo con GitHub:

1. Crear un fork.
2. Clonar el fork.
3. Crear una rama de trabajo.
4. Modificar o añadir archivos.
5. Hacer commit.
6. Subir la rama al fork.
7. Crear una Pull Request hacia el repositorio original.

## Instrucciones para estudiantes

Cada estudiante debe crear un archivo dentro de la carpeta `estudiantes/` con el formato:

apellido-nombre.md

El archivo debe incluir:

- Nombre completo
- Usuario de GitHub
- Una breve expectativa sobre el curso
- Un comando Git aprendido en esta práctica

Ejemplo:

```md
# Ana Pérez

- Usuario GitHub: ana-perez
- Expectativa: aprender a automatizar procesos de integración y entrega.
- Comando aprendido: git checkout -b ejercicio
